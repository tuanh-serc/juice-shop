# Bảng ghi nhận lỗi - Nhóm: ______  (số thành viên: ___)

## Yêu cầu
- Mỗi thành viên: 4 lỗi, trong đó >= 2 Code quality và >= 2 Security.
- Nhóm 3 người làm đủ khối lượng như nhóm 4 người = 16 lỗi
  (>= 8 Code quality + >= 8 Security). Gợi ý chia: 6 - 5 - 5.
- Lỗi Security có thể là: lập trình, cấu hình, triển khai hoặc logic nghiệp vụ.
